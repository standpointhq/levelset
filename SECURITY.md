# Security

Levelset is read only: it has no tool that writes, places an order or changes an account. If you find a way to read data an account should not reach, to act as another account, or to get around authentication, please tell us privately.

## Reporting

Use **Report a vulnerability** on this repository's Security tab (GitHub private vulnerability reporting). Please do not open a public issue.

Include what you did, what you expected and what happened, and any request IDs or timestamps. We reply within five working days.

## Scope

- `https://standpointhq.com/api/v1/mcp` and its OAuth endpoints
- `https://mcp.standpointhq.com`

Please test only with your own account, do not degrade the service, and do not access other people's data.
